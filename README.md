# Альфа-Бизнес для селлеров

Интерактивное приложение к защите этапов 3–4 по дисциплине «Инновационный маркетинг».
Статический сайт без сборки: `index.html`, `styles.css`, `app.js`, шрифт в `fonts/`.

Разделы: кольца конкуренции и стратегическая группа, калькулятор стартовых тарифов, модель кассового разрыва, путь селлера (CJM) с партнёрами, орбита партнёров, карта позиционирования, пирамида бренда, айдентика 60-30-10, опрос по метафоре «Рост под контролем».

Локальный запуск: `python -m http.server 5173` в этой папке и открыть http://127.0.0.1:5173

Учебный проект, не официальный сайт Альфа-Банка.
